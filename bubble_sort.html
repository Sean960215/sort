一、操作原理

氣泡排序法（Bubble Sort）是最直覺的比較排序演算法之一。

核心概念：反覆掃描陣列，每次比較相鄰兩個元素，若左邊大於右邊就交換，讓較大元素逐步往右端移動。

每完成一輪（Pass）後，當輪最大值會固定在尾端；若某輪完全沒有交換，代表已排序完成，可提前結束。

二、演算法偽代碼

function bubbleSort(arr):
  n = arr.length
  for i = 0 to n-2:            // 共 n-1 輪
    swapped = false
    for j = 0 to n-2-i:        // 已就位尾端不再比較
      if arr[j] > arr[j+1]:
        swap(arr[j], arr[j+1])
        swapped = true
    if not swapped: break      // 提前結束最佳化

三、重點整理

  • 每輪會把一個最大值送到右端，未排序區間逐步縮小。
  • 有提前結束機制時，已排序陣列只需 O(n)。
  • 是穩定、原地排序，適合教學與小型資料。

四、時間 & 空間複雜度

情況 時間複雜度 說明
最佳情況 (Best) O(n) 第一輪無交換，直接結束
平均情況 (Average) O(n^2) 元素隨機分布
最壞情況 (Worst) O(n^2) 陣列完全逆序
空間複雜度 O(1) 原地排序，只需常數額外空間
穩定性 穩定 相等元素原本順序會保留
