## 氣泡排序法  
### 基本原理 : 氣泡排序是一種簡單的比較排序法。每一次比較兩個數字，比較大的數字往後放，每一輪最後的數字會是最大的。
### 操作方法 : 
1. 從陣列開頭開始，比較相鄰的兩個元素。
2. 如果前一個比後一個大，則交換位置。
3. 對每一對相鄰元素作同樣的工作，直到最後一對。此時最後一個元素會是最大值。
4. 針對剩下的 $n-1$ 個元素重複上述步驟。
### 複雜度分析 : 
* **平均時間複雜度：** $O(n^2)$
* **最差時間複雜度：** $O(n^2)$
* **空間複雜度：** $O(1)$
* **穩定性：** 穩定 (Stable)
