一、操作原理

合併排序法（Merge Sort）採用分治（Divide and Conquer）策略。

核心概念：先遞迴切分，再將兩個已排序子陣列線性合併，每層合併總成本為 O(n)。

總共有約 log n 層遞迴，因此時間複雜度穩定在 O(n log n)。

二、演算法偽代碼

function mergeSort(arr):
  if arr.length <= 1: return arr
  mid = floor(arr.length / 2)
  left = mergeSort(arr[0..mid-1])
  right = mergeSort(arr[mid..end])
  return merge(left, right)

function merge(left, right):
  result = []
  while left and right 都有元素:
    取較小者放入 result
  將剩餘元素接到 result 後面

三、重點整理

  • 先切分到子問題最小，再一路回推合併。
  • 時間複雜度穩定為 O(n log n)，不受資料分布影響。
  • 需要額外暫存空間，因此不是 O(1) 空間排序。

四、時間 & 空間複雜度

情況 時間複雜度 說明
最佳情況 (Best) O(n log n) 無論資料分布，仍需完整分割與合併
平均情況 (Average) O(n log n) 時間表現穩定
最壞情況 (Worst) O(n log n) 最壞情況仍維持同級
空間複雜度 O(n) 需要額外陣列進行合併
穩定性 穩定 相等元素可維持原始順序
