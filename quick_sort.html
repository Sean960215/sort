一、操作原理

快速排序法（Quick Sort）也是分治法，透過樞紐（pivot）將資料分區。

核心概念：把小於 pivot 的元素放左邊，大於 pivot 的放右邊，再對左右子區間遞迴排序。

平均效能很優秀，但若 pivot 選得不好，可能退化成平方時間。

二、演算法偽代碼

function quickSort(arr, left, right):
  if left >= right: return
  pivot = arr[(left + right) / 2]
  i = left, j = right
  while i <= j:
    while arr[i] < pivot: i++
    while arr[j] > pivot: j--
    if i <= j:
      swap(arr[i], arr[j])
      i++, j--
  quickSort(arr, left, j)
  quickSort(arr, i, right)

三、重點整理

  • 核心在分割品質，越平衡越接近 O(n log n)。
  • pivot 選不好時可能退化成 O(n^2)。
  • 原地性佳、平均速度快，是實務常用排序之一。

四、時間 & 空間複雜度

情況 時間複雜度 說明
最佳情況 (Best) O(n log n) 每次分割都接近平衡
平均情況 (Average) O(n log n) 實務上通常很快
最壞情況 (Worst) O(n^2) 分割極不平衡時退化
空間複雜度 O(log n) 主要來自遞迴呼叫堆疊
穩定性 不穩定 交換過程可能改變相等元素順序
